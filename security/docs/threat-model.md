# Mini threat model — index91

## Scope

Публичный учебный кейс `Публичный учебный кейс index91`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — SQL / целостность данных / параметризованные запросы

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | SQL injection | Строка пользователя конкатенируется в SQL | Placeholders/parameterized queries |
| T2 | Нарушение целостности | Score/attempt принимает некорректные значения | CHECK constraints + валидация |
| T3 | Дубликат операции | Повтор запроса создаёт повторную запись | Уникальный идентификатор попытки |
| T4 | Лишние поля | В БД сохраняется больше, чем нужно | Минимальная схема |
| T5 | Повреждение локальной БД | Приложение падает во время записи | Транзакция и rollback |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
